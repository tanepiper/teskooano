# asteroid.vert

Vertex shader for asteroid field particle positioning with belt rotation and instance matrix transformations.

## Overview

The asteroid vertex shader is responsible for transforming vertex positions in an instanced asteroid field, applying belt rotation to the entire field, and passing necessary data to the fragment shader for texture rendering and animation.

## Shader Features

- **Instance Matrix Transformations**: Transforms local vertex positions using instance matrices
- **Belt Rotation**: Applies rotation to the entire asteroid field around the Y-axis
- **Attribute Passing**: Passes texture indices, colors, and rotation data to fragment shader
- **Logarithmic Depth Buffer**: Supports logarithmic depth for large-scale rendering
- **Performance Optimization**: Efficient matrix operations for instanced rendering

## Shader Implementation

### Main Function

```glsl
void main() {
  // Transform position by instance matrix first
  vec4 instancePosition = instanceMatrix * vec4(position, 1.0);

  vColor = instanceColor;
  vTextureIndex = textureIndex;
  vInitialRotation = initialRotation;
  vUv = uv;

  // Apply belt rotation to the instanced position
  float cosAngle = cos(beltRotationAngle);
  float sinAngle = sin(beltRotationAngle);

  // Rotate around Y-axis (vertical axis)
  vec3 rotatedPosition = vec3(
    instancePosition.x * cosAngle - instancePosition.z * sinAngle,
    instancePosition.y,
    instancePosition.x * sinAngle + instancePosition.z * cosAngle
  );

  // Combine model, view, and projection matrices
  vec4 mvPosition = modelViewMatrix * vec4(rotatedPosition, 1.0);

  gl_Position = projectionMatrix * mvPosition;

  #include <logdepthbuf_vertex>
}
```

### Transformation Pipeline

1. **Instance Transformation**: Applies instance matrix to local vertex position
2. **Attribute Passing**: Passes instance color, texture index, rotation, and UV coordinates
3. **Belt Rotation**: Applies Y-axis rotation to the entire field
4. **View Transformation**: Transforms to view space using model-view matrix
5. **Projection**: Transforms to clip space for rendering
6. **Depth Buffer**: Includes logarithmic depth buffer support

### Belt Rotation Implementation

The belt rotation is implemented using a 2D rotation matrix around the Y-axis:

```glsl
// Calculate rotation matrix components
float cosAngle = cos(beltRotationAngle);
float sinAngle = sin(beltRotationAngle);

// Apply rotation around Y-axis
vec3 rotatedPosition = vec3(
  instancePosition.x * cosAngle - instancePosition.z * sinAngle,
  instancePosition.y,
  instancePosition.x * sinAngle + instancePosition.z * cosAngle
);
```

This creates a rotation around the vertical axis, causing the entire asteroid field to rotate as a unit.

## Performance Considerations

- **Efficient Matrix Operations**: Uses optimized matrix multiplication
- **Minimal Calculations**: Only performs necessary transformations
- **Instance Support**: Leverages GPU instancing for performance
- **Depth Buffer**: Optimized for large-scale rendering

## Integration with Fragment Shader

The vertex shader works in conjunction with [[asteroid.frag]] to provide:

1. **Position Data**: Transformed positions for rendering
2. **Color Data**: Instance colors for color modulation
3. **Texture Data**: Texture indices and UV coordinates
4. **Animation Data**: Initial rotation for particle animation

## Dependencies

- **Three.js Common**: Standard Three.js shader utilities
- **Logarithmic Depth Buffer**: Large-scale rendering support
- **Instance Matrix**: THREE.InstancedMesh instance transformations
- **Model View Matrix**: Camera view transformations

The vertex shader is used by:

2. **[[AsteroidFieldMaterial]]**: Manages uniforms and updates
3. **THREE.InstancedMesh**: Provides instance matrices and colors
