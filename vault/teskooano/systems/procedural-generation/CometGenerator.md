# CometGenerator

Generates comets by class (short/long/interstellar) with appropriate orbital parameters and visual activity.

## Orbits

- Short: moderate e, near-current radius
- Long: high e, large semi-major axis, long periods
- Interstellar: hyperbolic (e>1), no period

## Visuals

- Activity drives coma radius, tail length, opacity and colors
